# Experience and finite source scope

Quick Find was absent: Shelf had All/Actives/Expiring category filters but no saved-product text finder. The new transient query matches every entered word against admitted local name/brand, normalizing case, spaces and diacritics. It preserves product order and combines with the original filters. Stored products have no admitted source text field to search; no new field or catalog source is invented. There is no persisted index, network lookup, query telemetry or clinical ranking. Query state resets when the active grant changes. Count/no-match/empty/unavailable states remain distinct. Enter dismisses input; Escape clears/blurs; Clear returns input focus. While finding, routine/guidance promotional cards are suppressed so matching products come first; recovery notices remain. Unknown expiry no longer produces a confident replacement claim.

Shelf and progress query results carry a transient observation generation. The feature hooks subscribe to the existing health-data lease and bound expiry; cache entries from a retired grant are withheld immediately, including same-owner regrant and A→B→A. Progress withholds previous totals during a fresh read. Explicit retry/reentry obtains fresh local evidence; the accepted no-implicit-retry behavior is preserved. Query-family keys and protected lease/auth/key/storage primitives are unchanged.

Onboarding product removal now admits one operation per pending row, disables repeated taps, handles refused/ambiguous settlement with a fresh authoritative local read where still admitted, and provides an honest error and retry. A stale or unmounted callback cannot initiate a replacement-grant read. Archive uses the existing Shelf availability gate and Back control; unreadable private storage no longer appears as an empty archive.

The Shelf chip rows/skeleton wrap under enlarged text; product rows can wrap the badge while retaining a readable name column. No shared design-system overhaul was made. The original exact row-class contract is preserved; the reflow is supplied by an additional style.

`source-scope.json` is the exhaustive 13-path list, with preimage/postimage Git blob SHA-1, SHA-256, mode and byte size. It includes ten source/worklist commits. Six production paths changed, three tests were added, two flow documents changed, and exactly the two generated source-worklist outputs changed. No original test was edited. The original worklist producer is unchanged and was used for every regeneration after flow/source changes.

Protected tree/blob frontier witnesses partition every preexisting object outside the exact source delta, this previously absent checkpoint and separately bound root handoff. They include all workflows, Security/OWASP/OSV/expiry rules/tests, DB/Edge/SQL, state, historical checkpoints/reviews/ADRs, auth/consent/storage/crypto, dependencies, native configuration and all other ungranted application routes/features. Main and PR10 remain their supplied heads. No central persistence, permission request, provider protocol, paid-positive claim, clinical computation, M2 ledger or release action was added.
