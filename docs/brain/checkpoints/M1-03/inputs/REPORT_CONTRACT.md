# Report contract
Entry: `docs/brain/checkpoints/M1-03/README.md`; structured report alongside it using the existing guarded report family plus only the tested explicitly issued M1-03 binding. Keep detailed gate/status matrix, source custody, exact execution receipts, relevant CI observation and proposed changes accessible on the branch.
For every executed check: actual command, cwd, environment/tool identity, source commit/tree, start/observation time, exit code, real pass/fail/skip/filter counts, raw safe artifact path/hash. Distinguish Codex execution from Brain independent reproduction; a legacy schema enum cannot relabel the actor. Record measured source and evidence-only delivery separately; bind PR checkout and actual final-head CI. Never borrow an earlier pass.
Keep source/integration/surface/native/provider/qualified/research/commercial/release axes separate. Pending, unavailable, cancelled or skipped is not PASS. Preserve original failures, with a short causal pointer to successor proof rather than copying thousands of historical artifacts. Markdown for human reports; functional JSON/byte receipts stay functional. No personal photos, JANUS reports, clinical data or credentials.
Return branch, actual latest pushed SHA, push/remote readback status, handoff path, top blocker and honest context health, then stop. Brain independently reviews the branch; founder does not transport long reports.
