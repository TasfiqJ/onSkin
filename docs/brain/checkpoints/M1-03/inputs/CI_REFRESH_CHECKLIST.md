# CI reading order
Resolve source HEAD/tree and PR merge checkout/tree/parents, then list exact-head runs. Read each original job and actual raw execution outcomes, not only the displayed step conclusion or final acceptance. `continue-on-error` or skipped work can coexist with a misleadingly successful-looking intermediate step.
For Quality, separate repository/source/export/rehearsal jobs from the canonical credential-free database job. Verify whether a failure reached image preparation, startup, reset, SQL, tests, parity or cleanup. Preserve original primary and cleanup errors. For Security, separate scanner failure, raw finding, source-inventory mismatch, exception/review-date problem and missing/expired owner acceptance.
Record finite observation time. Running means running; a later rerun is a new execution identity. Same source tree does not equal same issuer/environment/authority. Do not change date, owner pins, source counts, scanner-return interpretation or protected policy to obtain success.
