# When a founder action is actually necessary
Do all available read-only and authorized ordinary-source work first. Do not ask for architecture or preferences. When an external blocker truly cannot be resolved within existing authority, create one consolidated pending packet, not a stream of vague requests.
For each indispensable item give: exact gate and reason; actual responsible owner; minimal action and safe place to perform it; no secret in chat/Git; minimum amount/provider and lifecycle obligations if any money is needed; current zero-cost alternative considered; expected returned sanitized evidence; what remains unauthorized after completion. Distinguish Brain's exact-code review request from founder authentication/spend/release and qualified professional signoff. Never create or renew those approvals on their behalf.
Preparing the packet is authorized. Spending, authenticating a registry/provider, collecting hosted personal data or using a paid sandbox is not. No owner action is requested merely because historical green needs re-creating.
