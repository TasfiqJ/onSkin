# What would make this night useful

The next review should receive: repaired native/source bindings and a reliable pushed evidence packet; reproducible executable scanner-candidate code with genuine supported runs rather than a proposal to try later; complete current-source coverage and source-bound findings reconciliation; and a precise answer about any remaining protected/external admission prerequisite.

A useful partial outcome is actual independently reproducible implementation plus a concrete incompatible dependency/rule/environment finding and finished other ready work. It is not a generic BLOCKED list, repeated unchanged tests, new screenshots for unchanged screens, unreviewed gate renewal or premature M2 features. No promise is made that external acceptance can be completed overnight.
