# Only if indispensable

The founder is not a technical decision maker for individual implementation choices. Prepare a single precise action packet only when an actual protected custodian, provider, independently qualified reviewer, or paid tool is indispensable. Describe the original authority issuer, target/version/head, observable missing receipt, expiry and least-privilege action. No credentials/hardware/vendor purchase requests for steps that can be simulated or verified in offline source. Do not ask the founder to merge, authorize M2, extend G97, or relax a blocked scanner gate.
