On cloud capability failure, report exact command, raw exit, runner identity and minimal permitted environment/repository action. Never fall back to the founder's Windows disk/WSL or install credentials. If a healthy cloud runtime cannot support the sealed candidate, do not relabel an unsealed run as accepted; request an appropriate authorized cloud capability/runner without changing protected workflow under this issuance.

At most two distinct useful candidate-only SQL/TS/fixpoint probes per class; do not blindly rerun expensive unchanged suites or flood CI. No self-issued owner receipt/waiver, no Security exception/expiry rewrite, no main merge/M2/release. Preserve safe stage commits; Brain decides next steps.
