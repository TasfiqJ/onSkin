## State machine and bounded implementation

Accepted current UI/source/lease → queued serialized private operation →
failed-read-safe private read → content-key read/decrypt → synchronous transform
of products and mirror outbox → conflict reread → key/encryption preparation →
latest synchronous admission → native setItem invocation → fulfilled or
ambiguous error → canonical readback → eligible screen publication.

Preparation before native write invocation is cancellable. Native invocation
is the JavaScript-observable admission boundary, not proof of physical storage
durability or an atomic OS transaction. An already invoked native write cannot
be promised abortable. The old third guard can restore adapter-visible bytes;
using volatile UI retirement there would manufacture rollback semantics.

Add a separate optional pre-native admission callback to updatePrivateItem,
checked at each prewrite asynchronous boundary and immediately before native
write invocation. Preserve the existing account/health checks, original third
guard, serialization, conflict/key/envelope checks and original compensation
for all old callers. No new global default or different encryption format.
Thread the opt-in only through Shelf remove/update for Remove/Discard and
their accepted confirmation. Use its existing monotonic Query/source/modal/
lease retirement; no retired callback may adopt a successor grant or Query.

Keep postinvoke UI retirement separate from account/health compensation.
Reconcile canonical storage after a successful invoked mutation, suppress stale
screen success, and retain truthful unconfirmed feedback on failed readback.
Own invalidation/refetch must be distinguished from unrelated replacement;
source/session ABA and readback races require explicit controls. Product and
outbox remain one encrypted transaction; notifications occur only after actual
successful commit. No UI-based restoration of a known committed write.
If any stronger guarantee needs a native atomic primitive or ungranted path,
record PARTIAL / OPEN_REQUIRED / UNAPPLIED with the exact interval.

Replace only the brittle current one-argument CORE-05 spelling assertion with
TypeScript AST checks for the real awaited callee, three ordered arguments,
captured authority and meaningful current lifecycle guard. Preserve every other
original assertion and the production route. Separate negative source mutations
must reject removed/reordered/replaced guards, times, callee, missing call,
no-op/shadowed/dead guards and weakened current owner/focus/health checks.
