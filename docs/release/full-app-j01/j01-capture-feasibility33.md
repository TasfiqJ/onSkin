## Early optical protocol to prepare before any collection

G1 owner: competent physical-iPhone imaging engineer. Predeclare intended
visible-pore target and cosmetic-only output granularity. Identify exact lens,
native photo pixel format/dimensions, crop and orientation, focus behavior,
capture distance/geometry, facial region, illumination/exposure/white balance,
motion, makeup/skin preparation, compression and processing transformations.
Measure useful resolving power and repeatability on actual supported iPhones;
quantify smallest useful visible structure at the native capture, not after
interpolation. State unsupported profiles and abstention/retake conditions.
Thresholds, smallest useful structure, device set and sample size remain UNKNOWN
until predeclared by the imaging/statistical owners. No sample count or cutoff
is invented here. First decide optical feasibility; do not assume a model can
recover absent native detail.

G2 owners: source-rights counsel, image scientist and statistician. Authenticate
exact dossier bytes and chain of rights for research/code/weights/photos/labels,
collection consent, retention/deletion and permitted uses/distribution. Define
reference/annotation reliability, exact inclusion/exclusion, device/tone/light/
region coverage, person-disjoint frozen evaluation and leakage controls before
model selection. No real-image intake, account creation or collection is
authorized by Campaign33. Missing provenance stays UNKNOWN/NOT_ACCEPTED.

G3 owners: independent image scientist/statistician. Freeze a truthful baseline
and intended single-scan claims before evaluating held-out supported strata.
Report errors, uncertainty, coverage, failure/retake/abstention and unsupported
configurations at each intended claim granularity. Predeclare acceptance and
failure rules, versioned code/model and immutable data manifests. A training
metric, demo screenshot, framing-quality score or test fixture is not this gate.

G4 owner: independent longitudinal reviewer. Even an accepted single-scan J01
does not admit quantitative change. Separately establish common-support capture,
repeatability/noise floor and change-claim validity. G4 is NOT_ACCEPTED; F18 and
J02-J27 remain deferred regardless. No treatment attribution or pore-reduction
claim is created by manual F09 comparison.

G5 owners: privacy/security, clinical/regulatory reviewers and native release
operator. Bind the exact signed iPhone archive, supported profiles, consent and
owner/capture epochs, encrypted raw/thumbnail/derived lifecycle, cancellation,
withdrawal/delete/key loss/process death, temporary plaintext cleanup and network
evidence. Prove zero egress if claimed. Test fairness/unsupported profiles,
VoiceOver/large text/retake explanations and exact reviewed cosmetic language.
Native camera startup, installed-device results and reviewer identity/signature
must be real; Expo web and unsigned exports do not replace them.
