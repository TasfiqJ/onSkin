# Phase 9 Edge Function Auth Matrix

| Function | Mode | Required proof |
| --- | --- | --- |
| `account-deletion` | User JWT required; POST-only execution | Missing auth is 401; valid-JWT non-POST is 405 before deletion work; oversized bodies are rejected by `USER_EDGE_BODY_MAX_BYTES` before auth/body parsing; caller can delete only self; Apple/PostHog/RevenueCat calls use timed fetches and bounded response reads; provider/storage failures do not return false success. |
| `data-export` | User JWT required; POST-only execution | Missing auth is 401; valid-JWT non-POST is 405 before export work; DB-backed keyed-hash per-user rate limit runs before export table reads or photo signed URL generation; exported photo signed URLs use configured short-lived TTLs; export rows are caller-scoped; service-role reads are filtered by user ID or user click tokens. |
| `consent-withdrawal` | User JWT required; POST-only execution | Missing auth is 401; valid-JWT non-POST is 405 before ledger/cleanup work; oversized bodies are rejected by `USER_EDGE_BODY_MAX_BYTES` before auth/body parsing; appends only caller revocation rows; cleanup scopes cloud photos, Ask safety audit, trend rows, community rows, and commerce click/order links to the caller; cleanup failures return and log only stable error codes. |
| `subscription-grants` | User JWT required; POST-only execution | Missing/wrong auth rejected; oversized bodies are rejected by `USER_EDGE_BODY_MAX_BYTES` before auth/body parsing; only current caller receives a grant. |
| `catalog-search` | User JWT required; POST-only execution | Missing auth rejected; oversized bodies are rejected by `USER_EDGE_BODY_MAX_BYTES` before auth/body parsing; DB-backed keyed-hash rate limit runs before request parsing, service-role search, or caller lookup telemetry; service-role search writes lookup event only for caller. |
| `catalog-lookup` | User JWT required; POST-only execution | Missing auth rejected; oversized bodies are rejected by `USER_EDGE_BODY_MAX_BYTES` before auth/body parsing; DB-backed keyed-hash rate limit runs before barcode parsing, service-role catalog reads, Open Beauty Facts calls, or caller lookup telemetry; Open Beauty Facts responses use timed fetches, bounded JSON reads, and capped product fields; barcode body sanitized; query-string barcode lookup is rejected; lookup event belongs to caller. |
| `catalog-report` | User JWT required; POST-only execution | Missing auth rejected; oversized bodies are rejected by `USER_EDGE_BODY_MAX_BYTES` before auth/body parsing; correction/report rows belong to caller; request body, proposed payload, and client context are allowlisted and sanitized before persistence. |
| `revenuecat-webhook` | External webhook; POST-only execution | Supabase JWT disabled only with RevenueCat auth/HMAC verification; bad shared auth is rejected before body reads; raw webhook bodies are bounded by `REVENUECAT_WEBHOOK_MAX_BYTES`; persisted webhook JSON is sanitized to an allowlisted event snapshot; entitlement mirror failures persist only stable error codes; live harness covers non-POST, forged auth, bad/stale signature, oversized body rejection, duplicate event id, initial purchase grant, renewal, cancellation, billing issue, expiration, refund revoke, and raw provider payload canary minimization. |
| `order-report-poll` | Scheduled service; POST-only execution | Inert without ShopMy key; once `SHOPMY_BRAND_API_KEY` exists, fails closed without `ORDER_REPORT_POLL_SECRET` and requires scheduler authorization before ShopMy API calls or service-role upserts; ShopMy responses use timed fetches and bounded JSON reads; live harness proves non-POST and missing/wrong-secret calls do not write `order_attributions` without using the real scheduler secret. |
| `growth-event` | Public web endpoint | Event and props allowlisted; no contact/health/product/barcode payloads accepted; oversized bodies are rejected by `PUBLIC_FORMS_MAX_BYTES`; DB-backed keyed-hash rate limit runs before Turnstile verification; Turnstile responses use timed fetches and bounded JSON reads. |
| `waitlist` | Public web endpoint | Email validated; attribution allowlisted and sanitized; oversized bodies are rejected by `PUBLIC_FORMS_MAX_BYTES`; DB-backed keyed-hash rate limit runs before Turnstile verification; Turnstile responses use timed fetches and bounded JSON reads. |

Strict Phase 9 signoff requires `phase9:live-edge-auth:strict` evidence for missing/invalid user JWTs, valid-JWT non-POST rejection across all user-JWT Edge Functions, oversized-body `413 payload_too_large` rejection across body-parsing user-JWT functions, malformed authenticated catalog/subscription requests, and deployed parity for provider timeout/response-size settings; `phase9:live-data-rights:strict` evidence for caller-only data export/delete, malformed photo-path omission, exported photo signed-URL expiry, and data-export `429`/keyed-hash limiter behavior; `phase9:live-consent-withdrawal:strict` evidence for deployed granular revocation cleanup; `phase9:live-public-forms:strict` evidence for public Turnstile, oversized-body no-write behavior, and 429/keyed-hash limiter behavior; `phase9:live-catalog-rate-limit:strict` evidence for catalog `429` behavior and redacted keyed-hash limiter samples; `phase9:live-order-report-poll:strict` evidence for scheduler-secret enforcement without authorized ShopMy polling; plus live negative tests for wrong-user access, webhook non-POST rejection, webhook signature failure, stale webhook signature, oversized webhook body rejection, duplicate webhook delivery, RevenueCat entitlement lifecycle transitions, RevenueCat raw-payload minimization, and log review.
