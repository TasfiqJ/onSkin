`signoff.md` is the authoritative human-readable approval roster. Do not
duplicate reviewer names in this manifest; the strict inspector cross-binds
the required signoff rows to the archive JSON review metadata.

`Client delivery` and `EAS Update channel` describe the accepted store-only
release policy. The strict inspector requires these exact values; an EAS build
profile channel or OTA update is not launch evidence.
