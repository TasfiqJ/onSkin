# Phase 11 ASO And Store Conversion Review

Status: BLOCKED until approved store copy, screenshots, and early conversion data exist.

## Goals

- improve store page conversion without expanding claims
- keep screenshots tied to shipped V1 functionality
- ensure privacy/data-safety labels match implementation
- avoid medical, diagnostic, treatment, cure, prevention, before/after, or guaranteed-result claims
- avoid fake reviews, fake testimonials, review gating, or undisclosed endorsement framing

## Review Inputs

| Input                                 | Status  |
| ------------------------------------- | ------- |
| App Store product page metrics        | BLOCKED |
| Play Store listing metrics            | BLOCKED |
| store copy source of truth            | BLOCKED |
| screenshot set using shipped features | BLOCKED |
| clinical/legal claims review          | BLOCKED |
| privacy/data safety review            | BLOCKED |
| support/review theme summary          | BLOCKED |

## Allowed Claim Themes

- routine organization
- shelf organization
- reviewed product-order conflicts
- progress comparison without scores or diagnosis
- reminders and habit support
- export, deletion, and privacy controls
- clearly disclosed paid links if enabled

## Banned Claim Themes

- diagnose, treat, cure, prevent, or detect conditions
- AI skin score, skin age, severity score, disease risk, hazard score
- guaranteed clearing, transformation, or clinical outcomes
- before/after gallery claims
- unreviewed dermatologist or medical endorsement
- fake social proof
- reward or pressure for positive reviews
