# Phase 10 Beta Surveys

Status: TEMPLATE. Host surveys in the approved research tool and avoid unnecessary sensitive data collection.

## Survey Rules

- Ask about usability, trust, and value. Do not ask for diagnosis, treatment history, prescriptions, pregnancy, photos, or free-form medical details.
- Use tester ID, wave, platform, and build number fields.
- Make every free-text field optional.
- Include a privacy reminder before free-text answers.
- Do not ask for public reviews or testimonials.

## Day 0 Survey

Purpose: capture first-session comprehension, value, catalog friction, privacy comfort, and price perception.

Required fields:

- tester ID
- platform
- build number
- wave
- completed onboarding: yes/no
- added at least one product: yes/no
- first value reached: yes/no/unsure
- easiest part
- most confusing part
- catalog result: found products, no matches, wrong matches, manual entry
- guidance trust: 1-5
- privacy comfort: 1-5
- would return tomorrow: yes/no/unsure
- Pro value clarity: 1-5
- expected fair annual price range
- any support issue: yes/no
- optional free text without sensitive details
