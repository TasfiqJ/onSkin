# Phase 10 Tester Recruitment Sheet

Status: TEMPLATE. Do not import personal data into analytics. Keep recruiting data in the approved support/research workspace with access limited to beta operators.

## Recruiting Goal

Recruit 50-100 real target users across iOS and Android who currently manage a skincare routine, own enough real products to test Smart Shelf, and are willing to give structured feedback without being asked for positive reviews.

## Cohort Mix

| Segment                       | Target | Why it matters                                             |
| ----------------------------- | -----: | ---------------------------------------------------------- |
| Routine beginners             | 20-30% | Tests onboarding clarity and first value                   |
| Routine optimizers            | 30-40% | Tests shelf depth, conflict trust, and retention           |
| Sensitive/privacy-aware users | 10-20% | Tests privacy language, photo comfort, export/delete trust |
| Catalog-heavy users           | 20-30% | Tests barcode/search/manual fallback under real shelves    |
| Paid-app/subscription users   | 20-30% | Tests pricing comprehension and Pro value                  |

## Screening Rules

Include:

- adults only
- users in supported launch countries
- users with a real skincare routine or intent to build one
- users willing to test catalog search, manual entry, routine check-off, and privacy controls

Exclude:

- minors
- users seeking medical diagnosis, acne treatment, prescription advice, or urgent skin-care help
- users unwilling to accept beta terms and no-medical-advice boundaries
- accounts created only to satisfy Google tester-count requirements without real use
- anyone offered compensation in exchange for ratings, reviews, testimonials, or positive social posts

## Incentive Rules

Allowed:

- small thank-you gift for completed research tasks when disclosed up front
- free beta access while testing
- interview compensation not tied to sentiment

Not allowed:

- reward for positive App Store or Play Store reviews
- request to leave a review before the app is public
- testimonial use without explicit separate permission
- creator or affiliate compensation without disclosure pack approval

## Wave Exit Notes

Each wave must produce a dated summary:

- number invited, installed, activated, retained, churned
- platform split
- build numbers
- top support themes
- top catalog themes
- top payment/restore themes
- privacy/deletion/export requests
- decision: continue, fix, hold, or stop
