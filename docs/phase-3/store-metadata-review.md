# Store Metadata Review

Status: draft only, not submitted  
Last updated: 2026-07-04

## Metadata Rules

- Store metadata must describe built functionality only.
- No disease, diagnosis, treatment, or skin-scoring claims.
- No "AI dermatologist" framing.
- No unreviewed derm/chemist claims.
- No partner/paid-link monetization claims unless affiliate flow and disclosures are live.
- Privacy policy, support, and account deletion URLs must be functional before submission.
