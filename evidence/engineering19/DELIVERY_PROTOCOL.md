# Permanent GitHub evidence delivery protocol

This file records the founder/independent Brain policy adopted for this evidence-only handoff. GitHub is the default future evidence delivery channel; manual founder ZIP transfer is no longer required. It supersedes older delivery-only prohibitions in the historical continuation prompt when publishing authorized, safe evidence. It does not authorize application source pushes, spending or release.

Use evidence-only branches separate from application branches. Inspect complete evidence for credentials, keys, customer/real-user/private clinical/device-identifying/protected sensitive data before upload. If unsafe material is already public, notify the founder immediately; never silently rewrite history. Publish complete UTF-8 reports, all38/all18 assessments, inventories, test/build/security/browser receipts, source patches, offline ancestry and continuation instructions. Split files above approximately250KiB into ordered readable parts with original/published sizes, SHA256, part order and exact patch reconstruction. Use immutable commit-pinned URLs.

Prepare and verify locally, then make one narrowly scoped evidence-only commit with [skip ci] after verifying workflow triggers; [skip ci] alone is not the safety mechanism. Verify all remote text bodies and hashes, PR/source preservation and zero publication-related Actions runs. Do not repeatedly commit binary ZIPs.

No Git LFS, paid GitHub services, Codespaces, hosted CI/native macOS runners, deployment, merge or release. No new repository, account configuration or billing changes without owner authorization. Stop any operation that could charge, leak or exceed authority. Routine product architecture/prioritization/debugging/local tests remain autonomous in future engineering assignments. Independent Brain retains source/security-gate/release-readiness acceptance; founder retains spending/account/service/merge/final-release authority. All38 requirements and18 gates remain UNACCEPTED; release NO_GO.

This publication performs no further engineering. Future engineering starts only under its applicable task authority, with the exact immutable source checkpoint verified first.
