# ADR-BR-001 — Beta-first execution and durable coordination

Status: ADOPTED FOR PLANNING AND LOCAL EXECUTION CONTROL. Author: independent Brain, under founder's explicit process-overhaul request of 2026-11-25.

Decision: install a GitHub control room; use one active outcome-based task, immutable revisions, Codex-owned implementation, independent reviews and machine-readable return pointers. Prioritize working runtime and a complete core loop before new unrelated features. Preserve existing E40 work before cutover.

Full-release requirements and gates are unchanged. A limited beta is proposed separately and remains unapproved for distribution. No new spending, hosted/native/production action or release is authorized.

Rationale: repeated large campaign prompts did not produce verified beta journeys and left environment blockers unowned. Increasing prompt size and titles is not an execution system. Source integrity matters, but repeated whole-history verification is not a substitute for demonstrated behavior.

Consequences: Brain must persist decisions and finish reviews. Codex must publish actual source evidence and outcomes. Founder relays one line and supplies genuine owner permissions only. Partial checkpoints are allowed at real session limits, but not presented as outcome completion. No guaranteed overnight runtime or release date.
